# Web research

1. 调用 `web_research`；它会在 runtime 内选择天气、GitHub、行情等结构化数据源，并使用多个搜索 provider 完成候选发现、原文读取、去重、相关段落压缩和证据整理。复杂问题通过 `depth`、`freshness`、`max_sources` 和 `domains` 控制研究范围。
2. 技术问题优先使用官方文档、官方 API、源代码仓库和原始论文；不要用搜索摘要代替原页面证据。
3. 对可能变化的信息核对发布日期和事实发生日期，必要时使用两个独立来源交叉验证。
4. 只把 `web_research` 返回的、实际读取并支持结论的 sources 列为来源；正文使用 source ID，末尾复制对应 `citation` 字段，不伪造链接或引用。
5. 原始来源无法访问时，说明已经尝试的地址和限制，不根据候选摘要补猜。
6. 最终先回答用户问题，再列关键证据、时间范围和仍有不确定性的部分。
