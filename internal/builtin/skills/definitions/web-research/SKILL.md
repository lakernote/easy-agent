# Web research

1. 先把问题拆成少量可验证的事实，再选择能访问互联网的 MCP；没有联网能力时直接说明需要启用什么。
2. 技术问题优先使用官方文档、源代码仓库和原始论文；不要用搜索摘要代替原页面证据。
3. 对可能变化的信息核对发布日期和事实发生日期，必要时使用两个独立来源交叉验证。
4. 只把实际打开并支持结论的页面列为来源，不伪造链接或引用。
5. 最终先回答用户问题，再列关键证据、时间范围和仍有不确定性的部分。
