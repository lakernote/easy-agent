# Browser validation

1. 只有已启用 Playwright MCP 或等价浏览器工具时使用；缺少能力时提示用户到“模型与工具”检测并启用。
2. 先读取页面结构和可访问名称，再通过角色、标签或稳定文本定位元素；避免依赖脆弱的坐标点击。
3. 按用户路径复现问题，同时检查控制台错误、失败请求、加载状态和关键 DOM 状态。
4. 修复后重新加载页面，并至少验证原失败路径、一个相邻路径和窄屏布局。
5. 报告实际执行的步骤、观察到的证据和未验证范围；不要仅凭截图宣称功能正常。
